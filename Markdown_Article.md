## Introduction

Markdown is a lightweight markup language used to format text. It is commonly used to create README files, documentation, and project notes on GitHub.

## 1. Headings

Markdown supports different heading levels using the `#` symbol.

# Heading 1
## Heading 2
### Heading 3
